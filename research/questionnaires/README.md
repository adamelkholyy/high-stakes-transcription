# Questionnaire archive

These documents preserve the questionnaires used during the dissertation
research. They are reference material only: the prototype does not render the
forms, collect answers, identify participants, or write behavioural study logs.

- `police-feedback.md` — the longer police-feedback questionnaire.
- `participant-questionnaire.md` — the short participant-study questionnaire.

The wording, options, scale anchors, and required/optional status were copied
from the former runtime definitions in `src/study/`.
